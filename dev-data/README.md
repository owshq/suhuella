# Dev data

Localhost fixtures for SuHuella Web. Production never loads this folder.

```text
dev-data/
  invoices/factura-enero.pdf
  invoices/factura-febrero.pdf
  contracts/contrato-cliente.docx
  pictures/captura-yala.png
  mixed/nota-reunion.txt
```

On `http://localhost:3000/sources`, **Developer Sources → Load demo data** indexes these names without opening Chrome’s picker.

You can also **Add local folder…** and pick this directory if you want a real File System Access handle.
